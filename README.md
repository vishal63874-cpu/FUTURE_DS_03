# FUTURE_DS_03 – Bank Marketing Campaign Conversion Analysis

## 📊 Project Overview

This project analyzes the **Bank Marketing Campaign Dataset** to understand customer conversion patterns and campaign performance.

The dashboard was created using **Microsoft Power BI** as part of the **Future Interns Data Science & Analytics Task 3**.

## 🎯 Objectives

- Analyze overall customer conversion rate
- Identify customer segments with higher conversions
- Compare conversions across job and education categories
- Analyze conversion by contact method
- Analyze monthly campaign performance
- Compare conversions based on housing loan status
- Examine campaign-level conversion patterns
